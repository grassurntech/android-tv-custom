# One glob pattern per line (fnmatch). Matching is case-insensitive. A line starting with # is a comment;
# the scripts also ignore anything after a space, tab or # on a pattern line, but keep reasons on their own
# comment line above the pattern so every reader of this file sees the bare pattern.
# Used by .claude/hooks/tv-safety.py, and must be used by any product script that disables packages.
# Seed list: verify on a real device with `dumpsys package <name>` and add TCL-specific names as found.
