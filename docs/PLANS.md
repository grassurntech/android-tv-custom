# Plans

> **Purpose:** How execution plans are written, where they live (exec-plans/active → completed), and current priorities.
>
> **Last updated:** 2026-11-19

- One file per plan in `exec-plans/active/`, named `YYYY-MM-DD-<topic>.md`, written as checkbox tasks that follow an accepted design doc.
- When every task is done, move the file to `exec-plans/completed/` and update the doc-update rule's checklist.
- Known shortcuts go in [tech-debt-tracker.md](exec-plans/tech-debt-tracker.md).
